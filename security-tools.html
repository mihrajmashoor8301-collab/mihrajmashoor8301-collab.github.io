http HTTP Security Headers Reference

Essential HTTP response headers used to protect modern web applications from Clickjacking, XSS, and transport downgrade attacks.

Strict-Transport-Security (HSTS) Transport Layer
Strict-Transport-Security: max-age=31536000; includeSubDomains; preload

Forces web browsers to communicate exclusively over encrypted HTTPS for the next year (31,536,000 seconds), permanently defeating SSL stripping downgrade attacks.

X-Frame-Options Clickjacking Defense
X-Frame-Options: DENY

Instructs the browser never to render this web page inside an <iframe>, <frame>, or <object>, preventing transparent overlay Clickjacking attacks.

Content-Security-Policy (CSP) XSS Mitigation
Content-Security-Policy: default-src 'self'; script-src 'self'; object-src 'none'

Specifies authorized origins from which scripts, images, and fonts may be loaded, mitigating Cross-Site Scripting (XSS) and data exfiltration.

Set-Cookie Security Flags Session Security
Set-Cookie: session=xyz123; Path=/; Secure; HttpOnly; SameSite=Strict

Combines HttpOnly (blocks JavaScript access via document.cookie), Secure (HTTPS-only transmission), and SameSite=Strict (blocks Cross-Site Request Forgery CSRF).
