Security Tools Command Index & Quick Reference

High-density command index covering reconnaissance, web testing, exploitation, password analysis, and traffic tools.

Overview

Security Tools Command Index & Quick Reference is a consolidated cheat sheet cataloging essential syntax, common flags, and usage patterns across the primary reconnaissance, web auditing, exploitation, and traffic analysis utilities documented throughout this handbook.

Core Concepts

This reference organizes tools by their operational phase in an authorized assessment, providing copy-ready command templates optimized for terminal productivity.

Tool Quick-Lookup Table

  • Reconnaissance & Scanning: nmap, dig, whois, whatweb
  • Web Application Auditing: ffuf, curl, burpsuite
  • Vulnerability Research & Exploits: searchsploit, msfconsole, msfvenom
  • Credential Security: john, hashid, hydra
  • Traffic & Protocol Analysis: wireshark, tcpdump, netcat
  • Host Administration & Hardening: chmod, find, ufw, systemctl

Commands & Practical Examples

1. Reconnaissance & Discovery Commands

BASH // RECONNAISSANCE SHORTCUTSNMAP & DNS
# Fast ping sweep on local subnet
$ nmap -sn 192.168.1.0/24

# Full TCP port scan with timing T4
$ nmap -p- -T4 192.168.1.10

# Service version detection with default safe scripts
$ nmap -sV -sC -p 22,80,443,8080 -oA scan_results 192.168.1.10

# Query all authoritative DNS records
$ dig target.local ANY +noall +answer

2. Web Application Testing Commands

BASH // WEB AUDITING SHORTCUTSFFUF & CURL
# Directory and route fuzzing
$ ffuf -w /usr/share/wordlists/dirb/common.txt -u http://192.168.1.10/FUZZ -mc 200,301

# Inspect HTTP response headers
$ curl -I http://192.168.1.10

# Test HTTP POST request with form data
$ curl -X POST -d "user=admin&pass=test" http://192.168.1.10/login.php

3. Vulnerability Research & Metasploit Commands

BASH & MSF // VULNERABILITY WORKFLOWSSEARCHSPLOIT & MSF
# Search local Exploit-DB by product and version
$ searchsploit "Apache 2.4.49"

# Search by CVE and show web URLs
$ searchsploit --cve CVE-2021-41773 -w

# Launch Metasploit quietly
$ msfconsole -q

# Metasploit standard configuration pattern
msf6 > use auxiliary/scanner/portscan/tcp
msf6 auxiliary(...) > set RHOSTS 192.168.1.10
msf6 auxiliary(...) > run

4. Passwords, Hashes & Netcat Commands

BASH // CREDENTIALS & SHELLSJOHN & NETCAT
# Identify hash type
$ hashid "$6$saltsalt$..."

# Offline password audit with John the Ripper
$ john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt

# Start Netcat reverse shell listener
$ nc -lvnp 4444

# Test TCP port connection
$ nc -zv 192.168.1.10 22 80 443

Practical Workflow

  1. Select Phase: Identify current assessment stage (Discovery → Enumeration → Verification).
  2. Copy Template: Copy targeted command block.
  3. Update Parameters: Replace target IP address, port numbers, and wordlist paths.
  4. Document Outputs: Ensure all command executions save logs (-oA, -oN, or shell redirection > output.txt).

Common Mistakes & Troubleshooting

  • Wordlist Paths: Wordlist locations vary across distributions. Verify file exists (e.g. ls -l /usr/share/wordlists/rockyou.txt) before running dictionary tools.
  • Missing Sudo on Raw Scans: Raw packet operations (such as SYN scan -sS or tcpdump) require root/sudo privileges.

Security Considerations & Scoping

Always verify that the target IP address matches your authorized scope before pasting and executing commands from cheat sheets.
