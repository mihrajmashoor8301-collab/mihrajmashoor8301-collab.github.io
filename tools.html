20 Standard Offensive & Defensive Tools
01

Nmap (Network Mapper)

Category: Network Exploration & Port Auditing
menu_book Handbook Standard Kali Tool
Purpose:

Rapid network host discovery, open port enumeration, service version detection, OS fingerprinting, and automated vulnerability audits via NSE Lua scripts.

Installation & Usage: 
sudo apt-get install nmap -y
nmap -sC -sV -p- -T4 10.10.110.45
Key Options:
-sS TCP SYN scan -sV Service versions -O OS detection -sC Default scripts -oA All output formats
Defensive Perspective:

Monitored by firewalls and SIEM. To minimize alerts in internal assessments, lower packet rate (--max-rate 50) and use -n to skip DNS flood queries.

02

Burp Suite

Category: Web Application Intercepting Proxy
science Web Lab PortSwigger
Purpose:

Capturing, inspecting, and manipulating raw HTTP/HTTPS and WebSocket traffic in real time between web client and backend API servers.

Core Modules:

Proxy (Traffic interception), Repeater (Manual request crafting), Intruder (Parameter fuzzing), Sequencer (Entropy testing), Decoder, Extender.

Practice & Safe Lab:

PortSwigger Web Security Academy & TryHackMe OWASP Top 10 rooms. Configure local browser to forward traffic through 127.0.0.1:8080.

Category: Deep Packet Inspection & PCAP Analysis

Purpose:

Essential Display Filters:

tcp.flags.syn == 1 and tcp.flags.ack == 0

LinPEAS & WinPEAS (PEASS-ng)

Category: Automated Privilege Escalation Enumeration
menu_book Linux Handbook science Lab #7
Purpose:

Searches for all possible local privilege escalation vectors on Linux, Windows, and macOS targets: misconfigured SUIDs, sudo rights, cronjobs, unquoted service paths, tokens, and kernel exploits.

Execution (In-Memory / Non-Destructive): 
# In-memory execution without touching disk
curl -L https://github.com/carlospolop/PEASS-ng/releases/latest/download/linpeas.sh | sh
./linpeas.sh -a > /dev/shm/linpeas.txt
Defensive Triage:

RED/YELLOW highlights in output indicate 99% privilege escalation pathways. Enforce principle of least privilege, audit sudoers file, remove unneeded SUID bits (chmod u-s), and monitor process spawning via Auditd.

Searchsploit (Exploit-DB CLI)

Category: Offline Exploit & CVE PoC Query Engine
menu_book Searchsploit Handbook science Lab #10
Purpose:

Performs ultra-fast offline queries against a local copy of the entire Exploit-DB repository directly from your terminal, without needing an active internet connection.

Common Commands: 
searchsploit apache 2.4.49
searchsploit -cve 2024-3094
searchsploit -m 48260  # Copy exploit PoC to current dir
Safe Usage in Labs:

Always inspect downloaded PoC source code before execution (searchsploit -x [ID]) to verify safety and understand the vulnerability payload structure.
