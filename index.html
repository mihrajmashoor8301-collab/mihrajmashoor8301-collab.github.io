Security Insight // SYN Flood & SYN Cookies: In a SYN flood denial-of-service attack, an adversary transmits millions of spoofed SYN packets without returning ACKs, exhausting the server's half-open connection backlog table. Linux mitigates this with SYN Cookies (tcp_syncookies = 1), encoding cryptographic connection state directly into the 32-bit Initial Sequence Number, eliminating kernel memory allocation until the final ACK arrives.

cancel VULNERABLE (DYNAMIC CONCATENATION)
SELECT * FROM users WHERE user = 'admin' OR '1'='1' AND pass = '...';
AST Logic Hijacked: The injected quotes break string boundary. The database parser creates a new logical OR node evaluating to TRUE, authenticating without password!
check_circle SAFE (PREPARED STATEMENT / AST FIXED)
SELECT * FROM users WHERE user = ? AND pass = ?;
AST Precompiled: Query syntax tree is compiled before input binding. The entire payload is treated as a scalar literal, searching for a user named admin' OR '1'='1.
Mitigation: Always use parameterized queries (PDO, PreparedStatement). Solve SQLi Lab ↗

CVSS 10.0 CRITICAL SUPPLY CHAIN

CVE-2024-3094 · XZ Utils Embedded Backdoor

Multi-stage malicious payload hidden in upstream release tarballs. Hooked RSA_public_decrypt in OpenSSH via liblzma.so.5 during systemd startup to allow pre-auth arbitrary remote command execution.

Detection: Audit liblzma versions (5.6.0 & 5.6.1 compromised)
Defense: Downgrade to 5.4.x, mandate signed reproducible builds
CVSS 8.1 HIGH RACE CONDITION

CVE-2024-6387 · regreSSHion OpenSSH RCE

Signal handler race condition (SIGALRM) in default OpenSSH server (sshd) on glibc-based Linux. An unauthenticated remote attacker can trigger heap state corruption to achieve root code execution.

Detection: Audit sshd logs for abrupt SIGALRM timeout terminations
Defense: Upgrade OpenSSH >= 9.8p1 or set LoginGraceTime 0 (DoS tradeoff)
CVSS 7.5 HIGH PROTOCOL DDOS

CVE-2023-44487 · HTTP/2 Rapid Reset

Abuse of the HTTP/2 stream multiplexing cancellation mechanism. Attackers send hundreds of thousands of request streams and immediately cancel them with RST_STREAM, overwhelming backend reverse proxies.

Detection: Monitor abnormal ratio of RST_STREAM to DATA frames
Defense: Enforce RST_STREAM velocity caps in NGINX, HAProxy, Envoy
