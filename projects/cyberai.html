info OVERVIEW & MISSION // 01

What is CyberAI?

psychology Purpose & Problem Solved

Security operations generate vast quantities of operational telemetry: system authentication attempts (`auth.log`), kernel messages, firewall connection drops, and security utility outputs. Analyzing these raw, unstructured logs manually during incident investigations or lab exercises is time-consuming and error-prone.

The portfolio project documentation describes CyberAI as a private, on-device telemetry ingestion and triage platform. It ingests raw logs, normalizes them into structured incident timelines, and applies contextual anomaly detection heuristics combined with local neural reasoning to identify correlated attack patterns.

shield Privacy & Air-Gapped Philosophy

Security telemetry frequently contains sensitive IP addresses, usernames, hostnames, and password hash attempts. Sending these logs to cloud-based LLM APIs presents significant data exposure risks.

CyberAI guarantees complete data residency by executing Qwen3-Coder 30B locally via Ollama on Kali Linux. Telemetry is parsed, correlated, and triaged entirely in an air-gapped local environment with zero external telemetry.

Data Isolation & Defensive Controls

Operational logs and system authentication details remain on localhost at all times; zero prompt data is transmitted to cloud endpoints.

lock_open_right Read-Only Ingestion

rule Safe Automation Boundaries

neurology AI MODEL INTEGRATION // 06

Local AI Model & Context Pipeline

CyberAI leverages Qwen3-Coder 30B served locally through Ollama. The model's large context window and strong code and structured syntax comprehension make it well-suited for security log interpretation:

Sliding-Window Log Analysis

Chunks continuous log streams into coherent temporal windows, allowing the model to detect coordinated activity distributed across multiple minutes or hours.

Contextual Threat Scoring

Synthesizes raw anomalies into qualitative severity flags (e.g. low-frequency reconnaissance vs. active credential brute-forcing) with transparent reasoning traces.
